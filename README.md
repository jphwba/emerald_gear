# Emerald Gear

A Fabric mod for Minecraft that adds a full set of emerald tools and armor, sitting alongside diamond gear in the progression, with emeralds used both to craft and to repair the set.

## Tools
| Item | Attack Damage | Attack Speed | Mining Speed | Durability | Enchantability |
|---|---|---|---|---|---|
| Emerald Pickaxe | 5.0 | 1.0 | 5.0 | 455 | 22 |
| Emerald Axe | 10.0 | -2.0 | 5.0 | 455 | 22 |
| Emerald Shovel | 5.0 | -2.0 | 5.0 | 455 | 22 |
| Emerald Hoe | 5.0 | -2.0 | 5.0 | 455 | 22 |
| Emerald Sword | 7.5 | 1.0 | 5.0 | 455 | 22 |

## Armor
| Piece | Armor Points | Base Durability Multiplier |
|---|---|---|
| Emerald Helmet | 3 | 528 |
| Emerald Chestplate | 8 | 528 |
| Emerald Leggings | 6 | 528 |
| Emerald Boots | 3 | 528 |

## Features
### Crafting
All items in this mod can be crafted in survivial mode. The crafting recipes are the same as normal gear except uses emeralds.
